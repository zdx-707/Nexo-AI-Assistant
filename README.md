# Nexo AI Assistant 🚀

Nexo is a next-generation AI platform inspired by autonomous agents like Manus and OpenSource projects. It is designed to be an evolving AI companion that grows, learns, and adapts to its users.

## ✨ Key Features

- **Voice Interaction:** Full microphone support for seamless voice conversations.
- **Self-Learning System:** A unique "Growth" mechanic where the AI evolves from its initial state based on user interaction.
- **Web Intelligence:** Capability to read, analyze, and process any provided URL or link.
- **Hybrid Model Architecture:** Nexo integrates **5 different AI models** into a single intelligent chat interface.
- **Extensibility:** Advanced users can plug in their own AI models to customize the intelligence layer.
- **Tiered Intelligence:** Multiple performance levels (Standard, Pro, Max) to handle everything from basic tasks to complex reasoning.

## 🛠️ Tech Stack
- **Environment:** Node.js / Server-side
- **Package Manager:** pnpm
- **CLI/Automation:** PowerShell & Shell scripting
- **Core:** Integrated LLMs

## 🚀 Vision
The goal of Nexo is to bridge the gap between static chatbots and dynamic AI agents, providing a unified workspace where multiple AI "brains" work together to solve complex problems.
